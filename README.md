Este é um projeto independente feito por Milena e Leticia
Bakehonaha é uma visual novel, de suspense/terror que se passa em um reino. Nele, você é um ajudante da rainha que foi encaminhado para descobrir o que está acontecendo em Florena, uma pequena vila situada no reino de Serenova.
Tem uma doença estranha se espalhando por essa vila, com sintomas incomuns. Todos eles tem algo em comum: comeram as flores da padaria da família Gardelis. Será que você consegguirá descobrir o mistério?
